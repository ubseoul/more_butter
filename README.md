# Velvet Loop Studio (web)

Sprite sheet preview workshop for Rich Alucard. Open the site, upload a horizontal sprite strip
(PNG/WebP/JPG, transparent or solid-colour background), and it plays on a nightclub stage.

Once merged to `main`, `.github/workflows/pages.yml` deploys it to https://ubseoul.github.io/more_butter/.
Everything runs in the browser; nothing is uploaded anywhere.
